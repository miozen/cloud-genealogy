# P0-6 本地孤儿输出恢复夹具

状态：2026-10-31，仅供本地测试。没有命令行入口、Worker 路由或远端适配器；远程备份执行仍禁用。此夹具不是通用文件清理工具，也不是实际备份恢复或授权证明。

## 范围和所有权

夹具在操作系统临时目录下创建新私有根目录及 SQLite 日志，仅处理根据随机 attempt ID 派生的直接子目录。重新打开必须匹配根目录路径、设备/inode 和随机 capability 的摘要。监督器为已登记 attempt 创建目录并证明所有权：数据库记录 nonce 摘要和目录设备/inode，目录内标记绑定 nonce 和身份。恢复时检查目录身份、标记、允许的 mock 路径及文件类型，拒绝符号链接、硬链接、未知条目、替换目录、未知 ID、路径穿越和清理后路径重现。目录与数据库必须位于夹具私有根中，不能用此过程接管任意已有路径。

停止判断只是由本地测试监督器提供的布尔回调，不是可信的跨进程或跨实例停写证明。窗口仍持有时拒绝清理，只有本地窗口失效才允许；已完成窗口的输出予以保留并记录审计，保留不代表内容已通过验包。夹具清理不会影响应用 D1 历史或真实 R2。

## 状态、审计和故障

尝试经历 `planned → owned → cleaning → cleaned`，失败可进入 `failed` 后重试，完成窗口进入 `preserved`。SQLite 同事务记录持久化清理意图和不可更新、不可删除的审计；清理阶段再次持有 SQLite 写事务，复查文件和状态后以目录文件描述符约束逐项删除并写完成审计，竞争恢复由数据库串行化。默认删除依赖 Linux 的 `/proc/self/fd`、`O_DIRECTORY` 和 `O_NOFOLLOW`，环境不支持时失败，不退回递归路径删除；不兼容的平台尚未验证。每次操作前检查打开的目录链身份，打开子目录后对比 inode，拒绝可观察到的路径替换。所有权标记最后删除，完成审计前还须确认输出路径不存在。重复恢复只确认已有终态，不重复记完成审计。

文件删除与 SQLite 不构成原子事务：删除后、提交审计前中断时，持久化 `cleaning` 意图和缺失目录无法区分删除与移走，重试必须拒绝并要求审阅，不补记完成；若删除尚未确认时捕获到错误，即使原路径已消失也记录失败；此时不得以路径不存在推定删除成功。目录仍存在时重新核验后可重试。若部分删除导致所有权标记丢失，或身份/内容发生变化，拒绝继续并等待人工审查。清理前审计失败不删除，删除后审计失败保留清理意图供审阅；失败审计本身失败也保留意图。已计划但未完成所有权证明的目录不会被自动删除。

`npm run test:local-orphan-recovery` 覆盖所有权、路径及内容拒绝、清理失败、审计失败、幂等重试、两个恢复进程竞争，以及删除后审计前 SIGKILL 重启。本地 mock 备份子进程在验证及发布完成后被 SIGKILL，分别验证失效孤儿清理和完成输出保留。新增逐项删除后的强杀：标记仍在时可重试；标记已删时保守拒绝并待审查。另用独立进程在清理暂停期间替换目录，验证不会沿替换的符号链接删除外部文件，并拒绝未实际删除输出的成功声明。所有进程、数据和停止判断都是本地夹具。

## 未解决问题

- 本地私有目录和监督器独占仍是实验前提。目录描述符约束可避免沿替换的符号链接递归，但身份检查与 unlink/rmdir 并非原子操作；持有写权限的恶意进程仍可能在最后一次检查后替换条目或移动已打开目录。若进程在目录被移走后、记录错误前被强杀，重启看到持久化清理意图与路径缺失，仍无法区分已删除与被移走；现已拒绝自动补记完成。不能声称消除了所有 TOCTOU，也不能作为真实清理执行器。
- 仅在两个选定逐项删除边界强杀，没有模拟掉电或验证任意部分清理的可恢复性；标记丢失时有意停在人工审查。SQLite 和本地文件系统的实验不证明 Cloudflare D1/R2 的持久性与原子性。
- 本地恢复记录不接入 readiness，不证明写者停止、直传 PUT 排空、跨实例冻结或真实授权；远程执行保持禁用。

## 只读审阅证据（2026-10-31）

`scripts/local-orphan-review-fixture.mjs` 仅对已登记的单一测试 attempt 产生固定结构的本地观察：读取窗口和尝试状态、最多 100 条既有审计 ID/动作，以及固定位置目录与所有权标记的有限元数据和匹配状态。观察不记录新审计、不改变恢复状态、不扫描其他目录或寻找被移走的对象、不输出 capability、nonce、标记内容或文件内容。使用固定路径和 no-follow 打开；目录或标记在观察期间被检测到发生变化则拒绝出具结果。`PRAGMA query_only=ON` 下的测试确认该操作无需数据库写入。

结果始终为 `review_required` 且远程执行不可用。SHA-256 用于比较观察结果是否变化，验证时重新采集当前观察；它不是签名、可信时间戳、授权或不可篡改证明，持有文件或数据库写权限的主体可以伪造数据和哈希。审计触发器只是夹具内的修改约束，不能抵御数据库所有者改写。观察时 SQLite 和文件系统没有共同快照；未检测到变化不等于并发修改不存在，也不能证明删除完成、所有写者停止或对象不存在于其他位置。报告只在该次观察时有效，不可据此自动恢复或删除。

本地测试以真正的清理子进程在文件删除前暂停，移动目录后 SIGKILL；重启只读审阅报告原路径缺失，恢复持续拒绝，移走的目录保留。另覆盖标记丢失/符号链接、重复读取、进程重新打开、报告篡改或过期、审计变化、路径穿越，以及删除后审计失败和强杀的保守行为。
