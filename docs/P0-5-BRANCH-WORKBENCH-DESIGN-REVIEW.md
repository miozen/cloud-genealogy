# P0-5 房支成员与结构工作台：交互设计审查

状态：待业务确认；本文不开放成员或房支结构的前端写入。最后更新：2026-10-24。

## 已验证现状

- 后端已能在一个 `change_request` 内处理成员增删、房支 `create` / `rename` / `retire`，并以完整 revision snapshot 原子发布。
- 当前提案预览会返回关系、成员和房支结构候选，但没有返回基准房支树/成员表的专用只读模型，也不返回“退休被哪些成员或账号范围阻塞”的结构化依赖。
- 退休依赖会在审核与发布时由服务端重新校验；成员残留或 `account_scope` 引用均返回 `branch_retirement_in_use`。这保证了安全，但不足以让前端在创建草稿前提供可操作的迁移建议。
- 当前 API 只支持创建后读取 preview、提交、审核和发布；没有对既有 draft 的条目增删/修改 API。客户端不能伪造“保存即更新”的体验。
- 审核工作台首个 UI 仅编辑单条 canonical 亲属关系；成员与房支结构仍没有前端写入口。

## 推荐交互：两步草稿与影响预览

### 第一步：本地编排，不写权威数据

管理员在一个“房支变更编排器”中选择世系，读取当前 published revision 的房支树和成员快照；可在浏览器本地添加、移除、排序以下条目：

- 创建房支：名称、类型、可选父房；
- 改名：目标房支与新名称；
- 退休：目标房支；
- 成员增删：目标房支、人物、归属类型。

界面应将“退休房支”和“移除该房成员”联动呈现，而不是把两类条目分散在无关联表格中。关闭页面或选择丢弃时，本地编排直接消失，不触及草稿或已发布数据。

### 第二步：创建不可直接修改的服务端 draft，再预览

用户明确点击“创建草稿并生成预览”后，才调用现有 `POST /change-requests`。创建成功后立即读取预览：

- 分区显示关系、成员、房支结构的最终候选；
- 显示服务端返回的结构/关系校验问题；
- 退休条目显示阻塞依赖、受影响成员数量与账号范围引用数量；
- 只有预览有效且用户再次确认，才显示“提交审核”。

由于当前 draft 不可编辑，预览不合格或用户需要修改时，界面只能“丢弃本次草稿并回到本地编排器”；不得暗中创建第二份相同草稿，也不得在浏览器假装已更新服务端条目。

## 需要先补齐的只读契约

推荐新增仅管理员可读的、以 published revision 为基准的端点。它不应返回账户身份或可编辑的权限对象：

```text
GET /api/admin/lineages/:lineageId/branch-workbench
```

建议返回：

- `revisionId` 与 `pointerVersion`；
- 房支树：稳定 ID、父房 ID、名称、类型、退休状态；
- 成员快照：房支 ID、人物 ID、人物显示名、归属类型；
- 每个房支的成员计数；
- 每个房支是否存在账号范围引用及其**计数**，不返回账号身份。

创建 draft 后的 preview 建议增加 `retirementDependencies`：按房支返回最终成员数、账号范围引用数和阻塞代码。服务端仍必须在审核和发布时重算；该模型只用于可解释的预览，不能成为授权依据。

## 明确不在首个界面范围内

- 移动父房、合并、拆分、跨世系迁移、改变 `branch_kind`、物理删除；
- 通过退休自动迁移成员或自动删除账号范围；
- 直接编辑已创建的服务端 draft；
- 向编辑员开放成员或结构条目；
- 暴露账号范围所对应的账号身份。

## 待确认的业务选择

1. 是否采用“浏览器本地编排 → 创建不可编辑草稿 → 服务端预览 → 明确提交”的两步模型？**建议：是。**
2. 退休前端是否只显示依赖数量而不显示被引用的账号身份？**建议：是。**
3. 若预览发现退休依赖，是否允许用户在同一编排器中添加成员移除条目，但要求账号范围必须另行由管理员处理？**建议：是。**
4. 是否要求退休操作在提交前额外输入房支名称确认？**建议：是。**
5. 是否接受首个界面只支持结构 `create` / `rename` / `retire` 与成员 `add` / `remove`，其余结构操作继续后置？**建议：是。**

## 实现验收

- 新只读模型只读取当前 published revision；不绕过 revision snapshot 或权限校验。
- local Worker/D1 回归验证：依赖计数与实际审核/发布拦截一致，且不返回账号身份。
- 浏览器测试验证：取消本地编排不产生 draft；预览失败不显示提交；确认退休必须匹配目标名称。
- 不执行 preview/production 迁移、远程写入或部署。
