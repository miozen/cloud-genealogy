# P0-6 local-only 孤儿审阅签名测试夹具

状态：2026-10-31，仅设计与本机测试。无 CLI、业务接口、人工审批或远程适配器；不读取真实凭据，不访问 Cloudflare，真实远程执行保持禁用。

## 测试协议

`scripts/local-orphan-signature-fixture.mjs` 每次生成仅驻留内存的 Ed25519 测试密钥对；测试调用方单独向验证器提供可信公钥，签名数据本身不能选择或替换该公钥。签名覆盖固定协议域、测试运行 UUID、测试私有根的调用方标识 UUID、attempt UUID、验证器发出的 256 位随机挑战以及本地只读观察报告。数据以测试夹具约定的键排序 JSON 序列化；明确限制输入形状、大小和不安全类型，不宣称符合通用签名规范。

验证器在本进程内登记挑战与预期上下文；未登记挑战、不同上下文、被修改的内容、错误密钥或签名被拒绝，失败不消耗挑战，正确验证后只消费一次。同一实例不能重新签发已使用挑战；状态上限 1024。报告必须仍是 `review_required` 且 `remoteExecutionAvailable: false`，签名与验证都没有删除、恢复、审批或写入应用状态的能力。测试以真实隔离窗口/孤儿夹具产出的本地观察为输入。

## 显式边界与反例

- 根标识和运行 ID 是测试监督器传入的随机标签，不自动证明实际目录、进程、Cloudflare 环境或验证方身份。公钥由调用方假定可信，本原型不提供公钥分发、身份认证、密钥轮换或撤销。
- 签名仅证明相应密钥对字节的签署，不证明输入由可信观察产生。测试中伪造观察并用拥有的签名器签署后仍验证通过；签名后文件变化也不影响密码学验签。报告不能证明对象存在、已删除、当前新鲜或可安全处置。
- 私钥只在测试进程内存中且不导出，但进程被攻破或调用权被滥用时仍可伪造。内存中的挑战登记不是跨进程原子、持久或防回滚的账本，也没有过期时钟。进程重启后未知挑战被拒绝；测试特意重发同一挑战，演示旧签名可重放。不要把单进程单次验证声称为持久防重放。
- 不建立可信时间、追加留存或持久化证据，也不解决私有根外的恶意并发写入及 SQLite 与文件系统不具备共同快照。任何真实信任根、签发权限、授权与恢复处置都须另行设计和批准。

## 本地验证

`npm run test:local-orphan-signature` 覆盖本地观察的签名、正确公钥、篡改后重算未签名哈希、协议与挑战替换、上下文错配、冒充公钥、错误不消费挑战、并发待验证挑战、重复验证、重启/复用反例、不可信签名者和签名后状态变化。所有密钥和挑战均为测试临时值，不写入工程文件或读取用户密钥。
