# P0-6 测试环境恢复演练授权包

状态：演练前置材料已完成；等待一次性 remote 执行授权。最后更新：2026-10-25。

## 已确认的运行原则

- 恢复请求须由两位责任人分别确认；当前为操作流程，不是门限密码学。
- 至少保留三个已成功演练的加密恢复点。
- preview 是唯一远程测试环境，可在明确确认其数据可被覆盖后用于恢复演练；production 永不用于测试。
- 任何正式恢复、资源 binding 切换或 production 操作继续需要单独审批。

## 执行前仍须在本次授权中填写的事实

下列值不存在于仓库，不能由代码或文档猜测。授权人应在安全的审批记录中提供，秘密本身不应填入本文件：

| 项目 | 执行前必须明确的值 |
|---|---|
| 责任确认 | 两位确认责任人的可验证身份与本次确认记录。 |
| 演练窗口 | 起止时间、可中断条件及联系人。 |
| 源包 | backup ID、加密包 SHA-256、迁移基线、外部保管位置标识。 |
| 测试目标 | preview D1/R2 的名称/ID、所属 Cloudflare 账户；须确认该数据可被本次演练覆盖。 |
| 最小凭据 | 仅限本次测试目标的 D1/R2 创建、写入、读取与清理权限；不得复用生产全权限 token。 |
| 清理范围 | preview 中本次测试数据的重置方式及责任。 |

## 一次性执行授权应包含的措辞

授权必须明确允许以下动作，并仅限上表指定的测试资源：

1. 清空或重建 preview 的测试数据；
2. 使用加密备份包恢复 SQL 和对象至 preview；
3. 执行只读计数、哈希、外键和应用授权验证；
4. 记录演练结果；
5. 按约定保留或重置 preview 测试数据。

授权不得隐含允许：操作 production、部署 Worker、变更 Secrets、切换 binding、创建长期高权限 token，或把备份包上传到未批准的位置。

## 演练成功标准

- 加密包认证成功，manifest、迁移基线及所有文件 SHA-256 匹配；
- 人物、谱书、来源、revision、关系、房支、账号/角色/范围及审计计数与 manifest 一致；
- 每个媒体对象的稳定 ID、对象键、哈希、大小和 MIME 均可比对；local 演练已覆盖该项，remote 演练仍必须逐项执行，不得跳过后宣称通过；
- 外键检查无结果，应用健康检查和最低权限读取冒烟检查通过；
- 演练报告记录资源、结果、差异、清理结论和下一次演练日期；
- 测试资源已按授权清理，或已记录保留原因和新的到期时间。

## 当前阻断项

1. 当前没有真实 remote 备份包或已授权的最小权限凭据。
2. 当前没有真实 remote 备份包或已授权的媒体读取凭据，尚无法验证真实远程媒体引用完整性。
3. 两位责任人的身份、演练窗口和外部归档位置尚未提供到安全审批记录中。

在这些事实补齐并取得一次性执行授权前，保持 local-only。详细步骤见 `P0-6-ADMIN-RUNBOOK.md` 与 `P0-6-KEY-RECOVERY-DESIGN.md`。
