# 技术架构与运行约束

## 1. 推荐栈
- 前端：Vue 3、TypeScript、Vite、Vue Router；Element Plus（后台）、Tailwind CSS（门户/样式）。
- 世系：独立 TypeScript 图投影与布局模块，SVG 渲染；按需加载与视口裁剪；亲属网络采用独立布局策略。
- API：Hono on Cloudflare Workers；Zod 校验；OpenAPI 契约可选。
- 数据：Cloudflare D1（SQLite），Drizzle ORM / SQL 迁移；媒体 Cloudflare R2。
- 测试：Vitest、Workers 集成测试、Playwright E2E。
- 部署：Wrangler + GitHub Actions，独立 preview / production 环境。
- 结构：单仓库、模块化单体；同一 Vue 应用，Worker 提供 API 与静态资源。

## 2. 目录建议（由 Codex 首轮评审，不强制）
```text
family-genealogy/
  src/                 # Vue 页面与组件
  worker/              # Hono API 与服务端业务
  packages/domain/     # 纯 TypeScript 类型、投影、布局与规则
  migrations/          # D1 迁移
  tests/               # 单元、集成、E2E
  docs/                # 业务决策、架构、阶段记录
  AGENTS.md
```

## 3. 核心请求链
浏览器 → Worker（鉴权/输入校验/授权）→ D1/R2。世系 API 返回已授权、可渲染的关系片段；浏览器计算坐标与 SVG 绘制。禁止在 Worker 请求中生成全谱大图、转码视频或渲染大型 PDF。

## 4. 性能目标（待实测验证）
- 总人物规模初期约 1000；不要求一次显示所有节点。
- 默认逐支展开、按需查询，前端缓存已加载片段。
- 布局引擎与 DOM/SVG 解耦，避免未来换渲染层导致数据库重构。
- 初始目标：普通设备上 100～300 可见人物的操作保持流畅；性能指标与设备基线在 P0 测试中实测确认。
- 数据库查询必须有索引、分页/范围限制，避免 N+1 查询与全表扫描。

## 5. 登录与安全
- 管理员采用安全密码哈希、速率限制、短期服务端会话或可撤销签名会话、Secure/HttpOnly/SameSite Cookie；CSRF 防护与登录审计。
- R2 私有桶；访问需 Worker 授权或短时签名 URL；上传校验 MIME、大小、扩展名，采用随机对象键。
- 上传前压缩图片并生成缩略图；限制视频大小/数量，不承诺永久免费无限存储。
- Secrets 只放 Cloudflare Secrets/GitHub Secrets，禁止入库或日志输出。
- 对外公开接口采用限流、机器人滥用防护、输入清理和输出转义。

## 6. 免费套餐约束
- Workers、D1、R2 的免费额度及 CPU/请求限制以实施时 Cloudflare 官方文档为准，不能将当前数字视为永久合同。
- 目标是**免费套餐可运行**，不是保证永远零成本。
- R2 容量、操作次数与媒体上传限额需后台可观测；达到阈值时限制新上传。
- 不采用需要额外付费的基础服务作为 P0 强制依赖。

## 7. 备份与恢复：上线阻断项
- 备份类型：数据库逻辑导出、完整备份（数据库 + R2 文件 + manifest）、云谱开放格式导出、修订版本回退。
- manifest 至少包含 schema 版本、生成时间、文件数量、大小、SHA-256、关系引用与备份格式版本。
- 管理员可手动导出并下载；恢复流程必须先校验包、验证 schema 兼容、检查引用完整性、显示影响范围。
- 禁止未校验直接覆盖生产；优先恢复到独立测试环境，再执行正式切换。
- 恢复前备份当前生产状态；恢复操作需要二次确认和审计。
- 数据库和媒体必须有**Cloudflare 账户之外的独立副本**；不能仅将备份放同一 R2 桶。
- 自动备份需要评估 Cron/Workers/D1 官方导出能力的限制。不得宣称纯免费 Worker 可以无条件定时导出完整 D1 和 R2。
- P0 必须完成一次从独立备份恢复到空白测试环境的演练，并校验人物数、关系数、谱书、文件哈希及权限。

## 8. 可靠性
- D1 迁移须可重复部署、向前兼容并有恢复计划；禁止随意改生产表。
- 高风险关系写入使用原子批处理/事务能力，并发使用版本号或条件写入防覆盖。
- 分别保存业务审计、发布修订和备份记录；避免将审计日志当成备份。
