# 阶段路线与验收

## 工作方式
每阶段先审查设计与风险，确认后再编码。每次交付附变更文件、迁移、测试命令与结果、风险、未完成项、下一步建议。不得宣称未实际执行的测试已通过。

## P0-0 架构确认（已完成，仅文档）
- 核对 Cloudflare 免费额度、D1/R2/Workers API 约束与恢复方案。
- 设计 ER 图、关键关系状态机、统一/历史谱书投影、吊线布局规格、API 契约。
- 制定权限矩阵、媒体策略、备份演练方案、测试数据与验收基线。
- 列出未决问题及影响，等待确认后才写业务代码。

验收记录：`P0-0-DECISIONS.md` 已固化已确认决策、物理模型边界、投影/API 契约、权限策略与本地离线备份演练路径。用户已批准按推荐顺序进入 P0-1；生产资源操作仍需在相应阶段明确授权。

## P0-1 项目基础（已完成）
- 单仓库、Vue、Hono、D1 迁移、R2 绑定、预览/生产隔离、论坛式注册审核登录和基础权限。
- 验收：本地与预览环境可启动，最小 API 和权限测试通过。

验收记录：见 `P0-1-STATUS.md`。本地启动、D1 迁移、最小 API、权限测试及可重复的认证全流程集成测试均已验证。隔离 preview 曾用于运行时验证；本阶段及当前任务均未操作 production。10,000 次 PBKDF2 是审核制个人站点确认的基础防护，不等同于 OWASP 当前推荐工作因子。

## P0-2 人物/关系/来源
- 人物、婚配、过继、承谱、房支、来源谱书及未接续人物。
- 验收：至少五代、多房支、同名、过继、冲突谱书、未知父系的固定测试数据均可表达；无环与唯一承谱约束测试通过。

进度记录：见 P0-2-STATUS.md。核心模型、受权手工录入、原始主张生命周期、统一/历史双投影与固定验收数据均已完成。

## P0-3 传统吊线图
- 横向世代列、同辈纵排、正交线、逐支展开、搜索定位、缩放、右侧人物面板。
- 验收：在约 1000 人测试数据中按需展开；布局顺序稳定，节点不重叠；无关房支不受编辑影响；可导出 SVG。

验收记录：见 P0-3-STATUS.md。受权 canonical API、SVG 视图、缩放、定位、只读人物面板、SVG 导出及约 1000 人 local D1/Worker 集成回归均已完成；本地浏览器已人工确认主要交互正常。尚未对多种指定设备量化帧率。

## P0-4 历史双视图与完整亲属图
- 统一世系 / 指定谱书版本历史世系切换与差异标记；以人为中心的完整亲属图。
- 验收：历史原谱主张不被统一关系覆盖；生父与嗣父可同时辨识。

## P0-5 编修与发布
- 编辑、挂接、拆支、合并、预览、审核、修订、回收站和日志。
- 验收：未审核变更不进入正式世系；错误合并可纠正；回退不擦除审计历史；并发冲突可检测。

进度记录：见 `P0-5-STATUS.md`。已完成关系、成员归属与房支 `create` / `rename` / `retire` 的受控提案闭环，以及审核人指派、草稿可审计废弃和 local Worker/D1 回归；房支移动、合并、拆分、人物合并、物理删除和对象级审批规则仍待独立风险模型与业务确认。

## P0-6 备份恢复（上线阻断）
- 数据库/完整/开放格式备份；校验、预览、恢复演练、异地副本。
- 验收：在空白测试环境完整恢复，人物/关系/谱书/媒体数量和哈希匹配，权限可正常使用；演练过程有记录。

进度记录：见 `P0-6-STATUS.md`。已完成离线包 manifest、只读预检及 local D1/R2 隔离恢复基线；remote 备份、测试环境演练、加密保管和部署仍未实施。

## P1 家族门户与成员
登录、认领、隐私、公开主页、基础搜索与移动端适配。

## P2 内容与媒体
资讯、公告、留言、相册、评论；圈子可后置；图片缩略图、媒体配额和审核。

## P3 云祠、功德榜与家族财务
多座云祠、祖先纪念、捐赠公示、收支台账；不做在线支付。

## 回归测试最小集合
- 循环承谱拒绝；同一发布版本双承谱父亲拒绝；未知上行允许。
- 过继后生父保留；婚配多段及姓名不详可表达。
- 同名不同人不自动合并；不同谱书记载并存。
- 统一/历史视图不串数据；排行未知不被伪造。
- 未授权不可读取受限人物；未审核不公开。
- 发布、回退、并发冲突、删除/回收站均有审计。
- 备份包校验失败不得恢复；恢复前生产快照与独立环境演练。
